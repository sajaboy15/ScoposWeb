Scopos

Сценарии этого сайта

Сохранённые инструкции повторяются мгновенно, без обращения к модели. Если интерфейс поменяется, Scopos сам найдёт новые кнопки.

Ключ Claude

Scopos отвечает через Claude. Ключ хранится только в этом браузере и уходит только в API Anthropic. Создать его можно на console.anthropic.com в разделе API keys.

Что видит модель

Только названия кнопок, ссылок и полей на открытой странице и их разделы. Без скриншотов, без введённого текста и паролей.

Быстрый вызов

Alt + Shift + S открывает панель. Поменять сочетание можно на странице chrome://extensions/shortcuts.

Модель: Claude Opus 5.5 · Scopos 0.1.0
