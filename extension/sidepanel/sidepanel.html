Scopos

Сценарии этого сайта

Сохранённые инструкции повторяются мгновенно, без обращения к модели. Если интерфейс поменяется, Scopos сам найдёт новые кнопки.

Ключ Claude

Scopos отвечает через Claude. Ключ хранится только в этом браузере и уходит только в API Anthropic. Создать его можно на console.anthropic.com в разделе API keys. Если запущен локальный сервер Scopos с ключом, свой ключ не нужен, а кнопка «Передать ключ расширению» на его странице /setup один раз отдаёт ключ сюда, и дальше Scopos работает без сервера.

Что видит модель

Только названия кнопок, ссылок и полей на открытой странице и их разделы. Без скриншотов, без введённого текста и паролей. Повторный вопрос на том же экране отвечается из кэша в этом браузере, без запроса к Claude.

Быстрый вызов

Alt + Shift + S открывает панель. Поменять сочетание можно на странице chrome://extensions/shortcuts.

Лимит в месяц

Сколько Scopos может потратить на Claude за календарный месяц. Когда лимит исчерпан, работают готовые гайды и ответы из кэша, а новые вопросы ждут следующего месяца.
