Scopos

Три шага, и Scopos ведёт по любому сайту

Ключ Claude хранится только на этом компьютере, в файле рядом с проектом. В браузер и на чужие серверы он не уходит, только в API Anthropic.

1

Подключите Claude

Вставьте ключ из console.anthropic.com → API keys. Он начинается с sk-ant-.

2

Научите Scopos продукту

Scopos один раз сам пройдёт по Ledgerly: откроет каждый экран, вкладку и окно и запомнит все кнопки и поля. Потом Claude напишет по этой карте готовые гайды. Они работают мгновенно и без токенов, а новые вопросы отвечаются по всей карте сразу.

Агент нажимает только то, что открывает экраны и окна. Он ничего не заполняет, не сохраняет и не отправляет.

Изучить Ledgerly
3

Спросите что угодно

Нажмите «Спросить» внизу справа и задайте вопрос своими словами, например «как добавить нового клиента» или «где сменить тариф».

Открыть Ledgerly
4

Поставьте расширение в Chrome

С ним Scopos работает на любом сайте, не только на демо.

  1. Откройте chrome://extensions и включите «Режим разработчика» справа вверху.
  2. Нажмите «Загрузить распакованное» и выберите эту папку:
…
  1. Нажмите на значок Scopos на панели Chrome (или Alt+Shift+S), откройте «Настройки» и вставьте тот же ключ.

Chrome разрешает ставить расширения из папки только вручную, поэтому этот шаг за вами.
