# Scopos Web

AI-гид, который живёт внутри веб-продукта. Пользователь спрашивает «как выставить счёт», а Scopos
читает страницу, разбивает задачу на шаги и ведёт по ним мягким кольцом-указателем прямо по
интерфейсу, в том числе через переходы между страницами и модальные окна.

Две формы одного ядра:

| | Для кого | Как ставится |
|---|---|---|
| **Расширение для Chrome** (`extension/`) | команды продаж и внедрения, демо «мы уже выучили ваш продукт», внутренние инструменты | «Загрузить распакованное» |
| **Встраиваемый скрипт** (`dist/scopos.js`, загрузчик 2.3 КБ gzip) | софтверные вендоры, которые дают Scopos своим клиентам (как Frigade) | одна строка `<script>` или `<ScoposProvider>` в React (`docs/install.md`) |

Десктопная версия для Windows (UI Automation) живёт в репозитории [`scopos`](https://github.com/sajaboy15/scopos).

## Как Scopos учит продукт (как Frigade)

1. **Обход.** Агент один раз сам проходит по продукту: открывает каждый экран по ссылкам,
   нажимает вкладки, меню и кнопки, которые открывают формы и окна, и сохраняет полное дерево
   элементов каждого экрана. Получается карта: экраны, диалоги, панели и какая кнопка куда ведёт,
   с вариантами выпадающих списков.
2. **Безопасность обхода.** Агент ничего не вводит и не отправляет формы. Он нажимает то, что открывает
   экран, вкладку, меню, окно или форму («Добавить клиента», «Пригласить», Invite user, New load), изучает поля
   и закрывает форму без отправки. Он никогда не нажимает кнопки, которые завершают действие: «удалить»,
   «отправить», «оплатить», «сохранить», «подтвердить», «выйти» и похожие (русский, английский и ещё десяток языков).
   Формы открываются, только когда включена блокировка сети (ниже).
   Он не уходит с сайта, закрывает каждое окно, которое открыл, и не трогает кнопки других расширений.
   На время обхода включены три слоя защиты:
   - в расширении `declarativeNetRequest` блокирует для этой вкладки все запросы, кроме чтения (POST, PUT, PATCH, DELETE, WebSocket);
   - в самой странице заглушены `fetch`/XHR на запись, `sendBeacon`, WebSocket, отправка форм, `confirm`/`alert`/`print` и `window.open`.
     Заблокированный запрос получает ответ 403, поэтому приложение не зависает;
   - если адрес или текст ссылки похож на действие (`/delete`, `/logout`, `?action=`), её не открывают.

   Обучение всё равно лучше запускать под тестовым аккаунтом.
3. **Готовые гайды до конца.** Claude превращает карту в гайды по главным задачам: от перехода на нужный экран
   через каждое поле формы до кнопки, которая завершает дело («Сохранить клиента», «Send invite»).
   Если в форме не хватает финальной кнопки, Scopos дописывает её сам.
   Большой продукт пишется частями (связанные экраны вместе), и каждая часть знает, какие гайды уже есть.
   Гайды запускаются мгновенно и без токенов.
   Если гайд доходит до места, куда обход не заглядывал, он один раз достраивается по живой странице
   (около цента) и сохраняется: дальше он тоже бесплатный.
4. **Ответы по карте.** На новый вопрос Claude отвечает по всей карте сразу: шаги на других
   страницах указывают на точные кнопки и подставляют значения («ООО «Северный ветер»», «30 дней»).
   Скриншоты не нужны, страницу при каждом вопросе перечитывать не нужно.

Где запустить:
- в расширении: «Сценарии» → «Изучить продукт» на открытом сайте;
- на демо: http://localhost:4173/setup → «Изучить Ledgerly» (или любая страница с `?scopos-learn=1`).
  Во встраиваемом скрипте обучение включается только атрибутом `data-learn`, а работает только на localhost или с токеном вендора.
  Перед стартом всегда спрашивается подтверждение.

Сколько это стоит (замеры в своём Chrome с настоящим Claude):

| | Время | Цена |
|---|---|---|
| Обучение Ledgerly (10 экранов и окон, 8 гайдов до конца) | ~1,5 мин | $0.06, один раз |
| Обучение TMS для грузоперевозок (~60 экранов и окон, 18 форм, 50 гайдов) | ~3 мин | $0.18, один раз |
| Готовый гайд | мгновенно | $0 |
| Новый вопрос по карте | ~2,5 с | $0.05 первый, $0.004 следующие (кэш карты) |
| Тот же вопрос повторно (кеш ответов) | ~0.5 с | $0 |
| Новые экраны, которые человек открыл сам | — | $0 (карта дополняется без Claude) |

В сквозном тесте шаги гайдов проходились так, как это сделал бы человек. Найдено 100% шагов: на Ledgerly 34 из 34 в 8 гайдах, на TMS 45 из 45 в 6 гайдах.
Записей в продукт во время обучения — 0 (сервер считает каждую попытку записи).

Карта уходит в Claude с кешем промпта на час (`cache_control`), а длинные карты сокращаются до разделов, относящихся к вопросу.

## Автономность

- **Ключ один раз.** Если в расширении нет своего ключа, оно берёт Claude через локальный сервер Scopos (ключ вставлен на /setup).
  Свой ключ в настройках расширения делает его полностью независимым.
- **Обновляется само.** Распакованное расширение раз в минуту сверяет свои файлы с сервером и перезагружается,
  когда ничего не идёт (нет гайда и обхода). Открытые вкладки подхватывают новую версию без обновления страницы.
  На /setup видно, какая версия загружена в Chrome.
- **Карта растёт сама.** Когда человек открывает новый экран изученного продукта, Scopos дописывает его в карту без Claude.
  Набралось 3 новых экрана — раз в сутки дописываются гайды только для них.
- **Месячный лимит.** В настройках расширения «Лимит в месяц» (по умолчанию $2), на сервере `SCOPOS_MONTHLY_USD` (по умолчанию $5).
  Когда лимит исчерпан, готовые гайды и сохранённые ответы работают как обычно.
- **Нет доступа к сайту.** Если в Chrome доступ расширения к сайту ограничен, панель так и пишет и показывает кнопку «Разрешить доступ».
- **Свой тестовый Chrome.** `dev/ext-harness.mjs` запускает Chrome без окна с отдельным профилем и настоящим расширением,
  `dev/e2e-learn-and-guide.mjs` учит продукт и проходит гайды как человек. Для проверки не нужен ничей открытый браузер.

## Что умеет

- **Ответ шагами.** Модель получает текстовую карту страницы: кнопки, ссылки и поля с номерами и
  разделами. В ответ приходят шаги, каждый указывает на конкретный элемент.
- **Указатель по дуге.** Кольцо летит к кнопке по дуге, рамка мягко обводит её, карточка
  подсказывает действие. Шаг засчитывается сам, когда пользователь нажал кнопку, заполнил поле или
  выбрал пункт. Можно пройти и кнопкой «Далее».
- **Пересматривает план на новой странице.** Шаги для следующих страниц модель сначала угадывает. Если угаданной кнопки там нет, Scopos за секунду пересобирает оставшиеся шаги по тому, что реально на экране.
- **Многостраничные инструкции.** Состояние хранится вне страницы, поэтому после перехода или
  перезагрузки гид продолжает с нужного шага.
- **Поверх модальных окон.** Слой Scopos поднимается в верхний слой браузера (popover), поэтому
  указатель видно и внутри диалогов сайта.
- **Сценарии без токенов.** Удачный ответ или собственную запись можно сохранить как сценарий. Он
  запускается мгновенно и бесплатно, если вопрос совпал с его названием.
- **Сам чинится после релизов.** Если кнопку сценария переименовали или перенесли, Scopos одним
  маленьким запросом находит её заново и обновляет сценарий.
- **Экспорт сценариев на сайт.** Сценарии, записанные в расширении, копируются в JSON и
  подключаются к встраиваемому скрипту через `data-playbooks`.

## Приватность

Модель видит только названия элементов, их роль и раздел, а также заголовок и адрес страницы.
Скриншоты не делаются. Что пользователь ввёл в поля, не отправляется: в карте только «заполнено» или
«пусто». При записи сценария введённый текст тоже не сохраняется.

## Точность указателя

Как у Floating UI и у Frigade, кольцо не «запоминает» координаты, а следит за элементом:
- слушает прокрутку всех прокручиваемых родителей, `ResizeObserver` и `IntersectionObserver`;
- после перемещения элемента несколько кадров досчитывает позицию, пока она не перестанет меняться;
- обрезает рамку по видимой части (контейнеры с `overflow`), видит элементы в открытом shadow DOM и в iframe того же сайта;
- если кнопку перекрыло окно, пишет об этом, а не показывает в пустоту;
- если React перерисовал кнопку, находит её заново по «отпечатку» (текст, роль, путь, соседи; подход Similo):
  совпадение принимается от 0.70 и только с отрывом от второго кандидата.

Проверка: `dev/stress.html` и `dev/stress-check.js` — 14 трудных случаев (прокрутка в контейнере, вложенная прокрутка,
масштабированный родитель, дубли подписей, перерисовка, обрезка, перекрытие, shadow DOM, iframe, sticky и fixed, кнопка-иконка).
Во всех случаях элемент находится заново, сдвиг рамки 0 px. Даже при 1 кадре в секунду указатель в итоге встаёт на место.
`node dev/scan-selftest.mjs` — 70 модульных тестов карты и поиска.

## Плавность на слабом железе

- Анимируются только `transform` и `opacity`. Видеокарта собирает такие кадры без перерисовки страницы.
- Страница читается только по запросу: на вопрос или смену шага. Наблюдатели живут, только пока на экране указатель или гид ждёт элемент.
  `MutationObserver` живёт, только пока гид ждёт элемент.
- Позиция пересчитывается один раз за кадр (`requestAnimationFrame`) при прокрутке или изменении размера.
- На компьютерах с 4 ядрами или меньше и малым объёмом памяти пульсации останавливаются после пары циклов.
- Пульсация всегда идёт только 3 цикла, а в фоновой вкладке всё ставится на паузу.
- Полёт кольца ограничен по времени; на мелкие сдвиги (до 8 px) кольцо не перенацеливается заново.
- `prefers-reduced-motion` отключает полёты и оставляет только плавное появление.
- Весь интерфейс на странице живёт в закрытом shadow DOM: стили сайта и Scopos не мешают друг другу.

## Расширение: установка

1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. «Загрузить распакованное» → папка `extension`.
3. Нажмите на значок Scopos (или `Alt+Shift+S`), откройте «Настройки» и вставьте ключ Anthropic API.
4. Откройте любой веб-сервис и спросите, как что-то сделать.

Ключ хранится только в `chrome.storage.local` этого браузера и уходит только в `api.anthropic.com`.

## Встраиваемый скрипт для вендоров

```html
<script src="https://cdn.example.com/scopos.js"
        data-endpoint="/api/scopos"
        data-product="Ledgerly, счета и платежи"
        data-playbooks="/scopos-playbooks.json"
        async></script>
```

Загрузчик сразу рисует кнопку, а основная часть (44 КБ gzip) подгружается, когда браузер свободен; режим обучения — отдельный
файл, обычные пользователи его не скачивают. Установка через npm (`@scopos/react`, `@scopos/js`): `docs/install.md`.

Ключ Claude лежит только на сервере вендора. Готовый сервер-прокладка: `server/server.mjs`, Node 20+, без зависимостей,
или Docker (`deploy/`).
В нём есть лимит запросов на IP и проверка входных данных.

## Демо

```bash
npm run demo
```

Откройте http://localhost:4173/setup: там вставляется ключ Claude (он сохраняется в `.scopos-key.local` рядом с проектом и в git не попадает), есть кнопка проверки и путь к папке расширения.
Демо-продукт: http://localhost:4173. Это демо-продукт Ledgerly со счетами, командой и диалогом приглашения.
Кнопка «Спросить» внизу справа уже знает два сценария, они работают даже без ключа.
Чтобы отвечал Claude, перед запуском задайте `ANTHROPIC_API_KEY`.

Дизайн боковой панели без Chrome: http://localhost:4173/dev/panel-preview.html?state=running
(состояния: `empty`, `thinking`, `running`, `done`, `playbooks`, `error`).

## Устройство

```
extension/
  core/brain.js     запрос к Claude: промпт, схема ответа, разбор (общий для расширения и сервера)
  core/scan.js      карта страницы, описание элемента, повторный поиск элемента
  core/pointer.js   слой на странице: кольцо, рамка, карточка шага
  core/guide.js     проход по шагам, автопереход, ожидание элемента, запись сценария
  core/explore.js   обход продукта: карта экранов, окон и переходов
  core/guard.js     защита на время обхода: блок записей и диалогов в странице
  content.js        связка страницы с фоновым процессом
  background.js     состояние вкладок, сценарии, вызов Claude, самопочинка
  sidepanel/        боковая панель: вопрос, шаги, сценарии, настройки
sdk/widget.js       виджет для сайта вендора
sdk/build.mjs       сборка dist/scopos.js из ядра и виджета
server/server.mjs   сервер вендора: /api/scopos и демо
demo/index.html     демо-продукт Ledgerly
demo/tms/           тестовый TMS для грузоперевозок (грузы, водители, диспетчерская, счета), чтобы настраивать обход на большом продукте
dev/                стресс-стенд указателя, тесты карты, превью панели
research/           разборы Frigade, Floating UI, Similo и аудиты кода
```

Модели (у каждой задачи своя, по цене и качеству):
- `claude-sonnet-5-5` — ответы на вопросы (31 из 32 точных путей на TMS, ответ на языке вопроса) и написание гайдов
  (то же качество, что у Opus, за полцены);
- `claude-haiku-5-5` — найти переименованную кнопку (14 из 14).

Замеры и цена в месяц: `research/10-model-eval.md`, цены и ценность: `research/11-pricing-and-value.md`.

Везде адаптивное мышление, ответ ограничен JSON-схемой. Текст страницы передаётся как недоверенные данные:
инструкции со страницы модель не выполняет, а подставляемые значения берутся только из вопроса или вариантов списка.
Если модель откажет, сервер Anthropic сам повторит запрос на запасной модели (`fallbacks: "default"`).
Запрос собирается напрямую через `fetch`: один и тот же модуль работает в service worker расширения и в Node без сборщика.
